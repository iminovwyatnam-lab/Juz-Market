# Удаление аккаунтов продавцов

Это дополнение к последней версии Juz Market с поиском, блокировкой продавцов и чатом поддержки.

## Установка

1. В терминале сервера продавцов нажмите Ctrl+C.
2. Скопируйте содержимое папки `Juz Market` из архива в существующий проект с заменой совпадающих файлов. Не удаляйте папку проекта или `seller-server/data`.
3. Запустите сервер заново командой `npm run sellers` и обновите страницу сайта.

## Использование

Откройте «Админка → Пользователи → Аккаунты продавцов». У каждого продавца появилась кнопка «Удалить аккаунт». Эта кнопка также есть внутри кабинета продавца в режиме администратора.

Перед удалением показывается имя магазина и почта продавца с запросом подтверждения. При подтверждении удаляются только выбранный аккаунт продавца, его товары и фотографии товаров, связанная заявка и фотографии паспорта. Сеансы продавца отзываются: повторно войти в удалённый аккаунт нельзя. Начатый до удаления запрос на изменение товара не сможет восстановить его. Другие продавцы, покупатели, история заказов и переписка покупателей не меняются. После удаления из кабинета администратор возвращается к списку пользователей.

Действие требует действующий ключ администратора и записывается в журнал действий сервера. Оно необратимо; для временного закрытия магазина по-прежнему используется кнопка блокировки. Удаление не означает постоянный запрет новой регистрации: можно подать новую заявку, которая снова потребует одобрения.

## Обычные пользователи

Удаление аккаунтов покупателей в это дополнение пока не входит. Эти аккаунты хранятся в отдельном проекте `juz-market-auth` (порт 4001), исходников которого нет в предоставленном архиве. Для завершения этой части нужен архив папки `juz-market-auth` без `node_modules`, `.env` и файлов с реальными паролями, токенами или данными пользователей. Нужны код сервера, маршруты, модели/описание структуры хранилища и `package.json`.

## Состав изменений

- `seller-server/server.mjs`
- `seller-server/moderation.mjs`
- `src/admin/sellersApi.js`
- `src/admin/components/SellerAccounts.jsx`
- `src/admin/pages/SellerAccountPage.jsx`

Дизайн и остальные функции не изменены. Сборка, серверные проверки прав/очистки данных/сохранения после перезапуска и браузерные проверки подтверждения/отмены удаления пройдены на отдельной тестовой базе. Реальные аккаунты из вашего архива не удалялись.
